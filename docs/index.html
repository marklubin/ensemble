A pluggable runtime architecture for multi-persona sessions

ensemble — a scene simulator where the cast can come from anywhere.

Multi-persona scenes — debates, roundtables, interviews, writers' rooms — running on a thin scheduler with a pluggable per-seat runtime. Same session can mix Anthropic Managed Agents, a real Claude Code subprocess, and a human at the keyboard.

What ships in v1.5

The implementation lives in the repo at github.com/marklubin/ensemble:

  • Backend: Bun + Hono + Zod. Real MCP server with all 11 Host API tools. JWT-scoped tokens per (session, seat). SQLite-backed memory + persona library.
  • Three working runtimes: Anthropic (via DirectSdkRuntime while the Managed Agents beta API solidifies), Human (web UI bridge), and Claude Code (LocalCliTransport spawning claude -p per turn with Ensemble's MCP attached).
  • Web client: React + Vite + React Router. Templates picker, casting, persona library + editor, screenplay session view with streaming SSE, memory panel, moderator controls.
  • Tested: ~340 unit/integration/contract tests, ~40 component tests, Playwright templates suite, and a live API smoke against real Anthropic + real Claude Code subprocess.
